# STALZONE — Voxel PvPvE Extraction Shooter (Android)

Воксельный 3D extraction-шутер в сеттинге Чернобыльской Зоны Отчуждения, полностью адаптированный для смартфонов Android.

## Где скачать `.apk`
В Git-репозитории папка `build/` не хранится напрямую, поэтому `.apk` собирается автоматически через **GitHub Actions**:

1. После пуша проекта на GitHub подождите ~2–3 минуты, пока завершится сборка во вкладке **Actions → Build STALZONE APK**.
2. Скачайте готовый файл **`STALZONE.apk`**:
   - в разделе **Releases** (справа на главной странице репозитория → `STALZONE Android APK (Latest)`), **или**
   - внутри последнего запуска **Actions → Artifacts → `STALZONE-APK`**.

Также можно экспортировать `.apk` напрямую из Google AI Studio через меню настроек проекта.
